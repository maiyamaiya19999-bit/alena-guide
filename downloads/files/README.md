# Рабочее место Алёны — полная настройка с нуля

Этот пакет превращает твой Claude Code в готовую систему для блога: сценарии reels, длинные тексты и воронка в Telegram, лид-магнит-видеоурок, прогрев, продающий урок, гайды, презентации и карусели — всё в твоём голосе и твоей палитре. Claude уже знает, кто ты, твой метод, твою историю, аудиторию и границы: ему не надо ничего объяснять заново.

Иди по шагам ПО ПОРЯДКУ. Ничего не пропускай. Если застряла — шаг 8.

---

## Шаг 0. Что у тебя будет в конце

Claude Code с 16 командами (скиллами). Каждая вызывается словом со слэшем или обычной фразой:

| Скилл | Что делает |
|---|---|
| `/reels-expert` | Сценарий экспертного (объясняющего) reels из одной мысли — хук, тело, снятие вины в конце, под суфлёр |
| `/reels-story` | Сценарий reels с твоей историей (Анапа, «зачем я проснулась» → «быстрее бы проснуться») без закрытых тем |
| `/tg-posts` | Длинные полезные тексты для Telegram в твоём голосе: длинные предложения, короткие строки, воздух |
| `/tg` | Режим продюсера канала: подтягивает твои прошлые посты из `~/tg-assistant`, держит стиль и план |
| `/stories` | Серия из 6–8 сторис — только по твоей прямой команде, сама в контент-план не добавляется |
| `/voice-edit` | Переписывает сырой или нейросетевой текст твоим живым голосом |
| `/tg-funnel` | Воронка в Telegram: бот от бесплатного видеоурока до покупки «Отпусти тело», тексты каждого шага |
| `/lead-magnet` | Лид-магнит-видеоурок: сценарий по готовой структуре, сверка со стоп-листом |
| `/ca-tripwire` | Разбор аудитории по ступеням осознанности и проверка трипваера под неё |
| `/progrev` | Прогрев к открытию продаж: план по дням — reels и посты в Telegram (без сторис) |
| `/selling-lesson` | Продающий урок / вебинар: структура, смыслы, переход к продукту |
| `/guide` | Гайд-лендинг или статья страницей в интернете в твоём стиле |
| `/presentation` | Презентация к видеоуроку с местом под твоё видео |
| `/presentation-full` | Полноэкранная презентация + экспорт в PDF |
| `/carousel` | Карусель для Instagram 1080×1350, готовые PNG |
| `/parser` | Установка и работа с парсером reels по отдельной подробной инструкции |

Плюс:
- Папка `~/tg-assistant` — архив постов твоего канала (Claude сам его пополняет), черновики, план, мониторинг чужих каналов.
- Твой профиль, эталоны голоса и палитра — лежат в `~/.claude/brand/`, Claude читает их перед каждой задачей.
- `~/alena-setup/content/` — рабочие материалы (упаковка профиля, план созвонов).
- `~/alena-setup/parser/` — инструкция по парсеру reels (ставится отдельно, не обязателен).

## Шаг 1. База: установи Claude

Если Claude Code у тебя ещё не стоит — сначала пройди гайд «Claude с нуля»:
**https://maiyamaiya19999-bit.github.io/claude-montage-skill/start.html**

Там по шагам: аккаунт, подписка Pro, установка, первый запуск, проверка. Возвращайся сюда, когда тест из того гайда сработает.

## Шаг 2. Заведи GitHub и получи доступ

GitHub — это место, куда Claude складывает архив постов твоего канала и где публикуются твои гайды. Для установки пакета доступ к чужим репозиториям не нужен.

1. Зайди на **github.com** → Sign up → зарегистрируйся через свою почту (бесплатно, 3 минуты)
2. Подключи GitHub к своему Claude. Открой Claude Code и отправь ему:

```
Установи GitHub CLI (gh), если его нет, и залогинь меня в GitHub через браузер. Потом проверь, что вход выполнен.
```

Claude всё сделает сам, тебе нужно один раз подтвердить вход в открывшемся браузере. Соглашайся на подтверждения, которые он попросит.

## Шаг 3. Установи всё одной командой

Отправь своему Claude это сообщение целиком:

```
Скачай архив https://maiyamaiya19999-bit.github.io/alena-guide/downloads/alena-full-package.zip
и распакуй его в папку ~/alena-setup. Открой в ней файл INSTALL-FOR-CLAUDE.md
и выполни установку строго по нему. Потом отчитайся по каждому пункту.
```

Claude запросит несколько подтверждений — везде соглашайся. Он сам:
- проверит и поставит инструменты (git, gh, python3, Chrome для рендера)
- разложит все 16 скиллов по нужной папке
- положит твой профиль, эталоны голоса и палитру
- создаст папку `~/tg-assistant` для архива канала
- запишет свои постоянные правила (кто ты, как общаться, границы, стиль)
- прогонит проверки

**Он спросит две вещи для канала:** токен бота от @BotFather и юзернейм канала. Если бота ещё нет — так и скажи, он продолжит без него (это можно сделать позже, шаг 8).

В конце он выведет таблицу-отчёт. Если всё «готово» — переходи дальше.

## Шаг 4. Проверь себя: тестовое задание

Отправь Claude:

```
/reels-expert Мысль: тело не враг, который подводит, а единственный, кто всё это время был на твоей стороне.
```

Если в ответ пришёл сценарий на «ты», в женском роде, с хуком в первые секунды, без единого упражнения (всё лёжа и слушая) и со снятием вины в конце — всё работает. Если Claude начал спрашивать, кто ты и о чём блог, — установка не дошла до конца, смотри шаг 8.

## Шаг 5. Как пользоваться: готовые фразы под каждый скилл

Пиши Claude по-человечески. Вот рабочие формулировки — копируй и подставляй своё:

**Экспертный reels:**
```
/reels-expert Мысль: пока тело зажато, визуализация — это просто фантазии. Для тех, кто перепробовала аффирмации и марафоны.
```

**Reels с историей:**
```
/reels-story Про Новый год в Анапе: последний билет на поезд, родители против, море при +10 — и как телу впервые стало хорошо. Без названий книг.
```

**Пост в Telegram:**
```
/tg-posts Длинный текст про «не выдумывай, тебе кажется» — как обесценивание детских чувств делает взрослую, которая не доверяет телу. Финал: тебя не сломали — тебя зажали.
```

**Режим продюсера канала:**
```
/tg Посмотри мои последние посты и предложи план на неделю: 2 объясняющих текста, 1 про практику, 1 личный.
```

**Воронка в Telegram:**
```
/tg-funnel Собери цепочку бота: бесплатный видеоурок → «Отпусти тело» за 990 ₽. Первые 5 минут практики — бесплатно, ссылка на оплату внутри бота.
```

**Лид-магнит:**
```
/lead-magnet Собери сценарий бесплатного видеоурока по готовой структуре: «ты не ленивая и не сломанная». Сверь со стоп-листом перед выдачей.
```

**Аудитория и трипваер:**
```
/ca-tripwire Разбери сегмент «прошла всех врачей, всё в норме, а мне плохо» и проверь, попадает ли в него «Отпусти тело» и что сказать в первые 3 секунды ролика.
```

**Прогрев:**
```
/progrev Открываю продажи «Отпусти тело» через 7 дней. Составь прогрев по дням: reels и посты в Telegram, без сторис.
```

**Продающий урок:**
```
/selling-lesson Урок «Почему ты не можешь расслабиться, даже когда всё нормально», 30 минут, в конце — переход к «Отпусти тело».
```

**Гайд-лендинг:**
```
/guide Оформи этот текст как гайд в моём стиле: [вставь текст или приложи файл]. Покажи файл.
```

**Презентация к уроку (с местом под видео):**
```
/presentation Тема «Сначала разрядить, потом расслаблять». Вот тезисы урока: [тезисы]
```

**Презентация на весь экран + PDF:**
```
/presentation-full Тема «Почему аффирмации не работают на зажатом теле». Экспортируй в PDF.
```

**Карусель для Instagram:**
```
/carousel Тема «5 признаков, что ты давно живёшь на автопилоте». Отрендери в PNG.
```

К любому запросу можно прикладывать файлы и скрины — просто перетаскивай их в чат. Твои рабочие материалы лежат в `~/alena-setup/content/` — можно ссылаться на них: «возьми упаковку профиля из content».

**Про мат.** По умолчанию Claude пишет без мата. Твоя норма — максимум одно крепкое слово на текст, в кульминации; если текст его просит — скажи «можно одно крепкое в кульминации».

## Шаг 6. Правила

1. **Claude знает твой профиль.** Он строит контент только из твоих фактов. Если чего-то не знает — поставит пометку `[нужна деталь]` и спросит. Не просить его «придумать цифры».
2. **Границы абсолютны.** Закрытые темы из раздела «Границы» твоего PROFILE.md публично не раскрываются. Claude это знает; если вдруг проскочило — скажи «убери, это за границей», он перепишет.
3. **Ты не тренер.** Никаких упражнений, осанки и асан в кадре — всё человек получает лёжа и слушая. Если в тексте появилось «сделай», «разомни», «выпрями» — скажи «перепиши: я не тренер».
4. **Никаких обещаний-гарантий.** «Вылечу», «уберу боль», «100%», сроки результата — под запретом. Только от первого лица: «у меня было так». Claude сверяется с доказательной папкой сам.
5. **Слово «состояние» — не термин.** Замены: «чувствование телом», «ощущения в теле». Про финансовую независимость пока не говорим.
6. **Стиль — закон.** Пудрово-розовая палитра, Libre Baskerville + Inter, квадратные углы. Если результат выбивается (скруглённые углы, чужие цвета) — «приведи к моему стилю по style-guide.md».
7. **Claude и reels — всегда латиницей**, reels с маленькой буквы. Твой Claude это знает.
8. **Материалы Майи не выкладывать** в открытый доступ и не пересылать. Скиллы, промпты, шаблоны — только для твоей работы.
9. **Посты в канал публикуешь ты сама.** Claude пишет черновики в `~/tg-assistant/drafts/`, а в канал отправляешь ты — так у тебя контроль над каждым словом.
10. **Парсер не обязателен.** Если Claude сам предложит «давай поставлю парсер» — только по инструкции из `~/alena-setup/parser/` и только когда тебе это реально нужно.

## Шаг 7. Приучи Claude к себе

Установщик уже записал базовые правила. Добавь личное — отправь Claude:

```
Запомни: меня зовут Алёна, ник в Instagram — the.tsarevna, юзернейм Telegram-канала — [юзернейм], общайся со мной на «ты» и по-русски.
Мой продукт сейчас — набор практик «Отпусти тело» за 990 ₽ (потом 1490 ₽). Кодовое слово для директа — [слово].
```

Дальше добавляй что угодно по ходу работы: «запомни, что…» — он записывает это в память. Особенно полезно сразу зафиксировать юзернейм канала (он нужен для tg-assistant) и цены продуктов.

## Шаг 8. Если что-то не работает

| Проблема | Решение |
|---|---|
| Пакет не скачивается | Проверь интернет и повтори фразу из шага 3. Если не помогло — напиши Майе, она проверит ссылку |
| Claude спрашивает, кто я и о чём блог | Профиль не установился. Скажи: «проверь, что в ~/.claude/brand/ лежат PROFILE.md и TOV-SAMPLES.md, если нет — повтори пункт 4 из INSTALL-FOR-CLAUDE.md» |
| Скилл не находится (`/reels-expert` не срабатывает) | Скажи: «покажи список файлов в ~/.claude/commands и скопируй туда скиллы из ~/alena-setup/skills» |
| Текст не в моём голосе | Скажи: «перечитай PROFILE.md раздел про голос и TOV-SAMPLES.md и перепиши» |
| В сценарии появились упражнения | Скажи: «я не тренер, всё лёжа и слушая — перепиши по трём правилам из шапки PROFILE.md» |
| `/tg` не видит посты | Нужен `config.json`. Скажи: «создай ~/tg-assistant/config.json из config.example.json» и дай токен бота и юзернейм канала. Для публичного канала без бота: «запусти scrape_history.py --channel имя_канала» |
| Карусель / PDF не рендерится | Проверь, что установлен Google Chrome. Скажи: «проверь headless Chrome и отрендери снова» |
| Гайд без моих цветов | «Перечитай ~/.claude/brand/style-guide.md и приведи к стилю» |
| Claude завис или чудит | Новый чат + опиши задачу заново. Лечит почти всё |
| Всё сломалось совсем | Скажи: «переустанови всё по INSTALL-FOR-CLAUDE.md из ~/alena-setup» |

Остальное — к Майе.

## Как обновить пакет

Майя будет дополнять скиллы. Чтобы забрать обновления, отправь Claude:

```
Обнови мой пакет: скачай свежий архив https://maiyamaiya19999-bit.github.io/alena-guide/downloads/alena-full-package.zip,
распакуй в ~/alena-setup и выполни раздел «Обновление» из INSTALL-FOR-CLAUDE.md.
Мой PROFILE.md не перезаписывай без вопроса.
```

Он обновит скиллы и стиль, а `PROFILE.md` тронет только с твоего согласия — если ты вносила туда правки, он спросит, прежде чем что-то менять. Твои посты, черновики и `config.json` при обновлении не затираются.
