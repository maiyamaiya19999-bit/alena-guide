# Шаг 2 · Программа «Отпусти тело» — устройство продукта

Как набор практик превращается из «папки с аудио» в программу с планом и ощущением ведения — по образцу сильных программ (этапность, план по дням, путь клиента), в рамках Алёны: всё лёжа и слушая, без обещаний результата, без медицины.

---

## 1. Принцип программы

Продукт — те же 5 практик, но упакованные как **21-дневный план**: каждая участница знает, что слушать сегодня и почему именно в таком порядке. Это главное отличие от «сборника аудио», за которое не стыдно взять 990 ₽ и которое реально доводят до конца.

**Логика порядка — авторский алгоритм Алёны:**
разрядить (выгрузить накопленное) → письменные практики → расслабление тела → дать телу прожить желаемое (намерение) → повторить.

Все зовут расслабляться на «заряженном» теле — здесь сначала разгрузка. Это позиционирование зашито в каждый материал программы.

## 2. План 21 дня (ложится в PDF/бот одним экраном)

| Дни | Фаза | Что слушает | Письменное | Задача фазы |
|---|---|---|---|---|
| 1 | Старт | Аудио «Как слушать» + вечерняя практика | Вечерняя страница | Войти без усилий: один вечер — один ритуал |
| 2–7 | **Разгрузка** | Вечерняя практика ежедневно; днём по желанию «после рабочего дня» | Вечерняя страница ежедневно | Выгрузить голову и день из тела; вернуть вечер |
| 8–14 | **Тело учится отпускать** | Вечерняя + «когда накрыло» (по ситуации) + утренняя 2–3 раза | Вечерняя страница | Заметить: расслабление наступает быстрее; острые моменты — в практику, а не в срыв |
| 15–21 | **Желания** | Йога-нидра с намерением через день, в остальные — вечерняя | Вечерняя страница + 1 раз «что я хочу» без цензуры | Дать телу прожить желаемое в настоящем времени |
| 21+ | Навык | Свободный режим: вечерняя как ритуал, «когда накрыло» по ситуации, нидра 1–2 раза в неделю | По желанию | Практики остаются навсегда — телу уже знакома дорога |

**Правила для участницы (в первом видео):**
1. Лёжа. Всегда. Никаких «сесть с прямой спиной».
2. Уснула во время практики — это засчитывается.
3. Пропустила день — не навёрстываешь, просто продолжаешь. Чувство вины здесь не инструмент.
4. «Не получается расслабиться» — нормально первые дни, для этого есть отдельное видео.

## 3. Контент-структура материалов (что записать/собрать)

**Видео (по 5–8 минут, говорящая голова, можно снять батчем за один день):**
1. «Как всё устроено» — план 21 дня, правила, почему порядок принципиален.
2. «Почему тело держит напряжение» — механика: терпела → осело в теле → тревога → болотце.
3. «Сначала разрядить» — почему без разгрузки практики не работают.
4. «Если не получается расслабиться» — снятие вины + что делать с мыслями.
5. «Йога-нидра с намерением» — как формулировать желание в настоящем времени (без «Вселенной», от первого лица).

**Аудио:** 4 практики + нидра + «как слушать» (уже записаны дома — 🔴 перезаписать в нормальном качестве: тихая комната, петличка/диктофон близко, без обработки «под студию»).

**PDF на 1–2 страницы:** план 21 дня таблицей + правила. Собирается скиллом `/guide` в её палитре.

## 5. Путь клиентки (сквозной)

Reels (объясняющий) → бот: бесплатные 5 минут + урок → «проверь на себе» сегодня вечером → покупка 990 ₽ → план 21 дня → на 21-й день бот спрашивает отклик (это и сбор кейсов, и мостик) → предложение следующего шага (разбор / канал / позже курс).

**Сбор кейсов вшит в продукт:** отклик на 21-й день — по трём вопросам (что было с вечером/сном · что заметила в теле · что удивило). Ответы с разрешения — в блок отзывов сайта с пометкой «о наборе».

3. Где живёт продукт технически: бот с оплатой (какой конструктор) + закрытый канал с файлами?
4. Юрформа для приёма оплат (самозанятость?).
5. Подтвердить: 990 → 1490 после полной сборки — публичная дата повышения.
