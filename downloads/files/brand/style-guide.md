# Фирменный стиль Алёны (@the.tsarevna)

Пудрово-розовая гамма «царевны»: тёплый почти-белый фон, пыльная роза как акцент. Структура и типографика — как у maysoulme, цвета — свои.

**Откуда палитра.** В распаковке (часть 9, раздел 9.6 «эстетика») конкретные цвета не названы — там задан только визуальный код блога: **свет, зелень, натуральное, красивое в мелочах, путешествия** (красивые кружки, здоровая еда, эко-косметика). Поэтому цвета взяты из SPEC пакета (палитра «царевны» по умолчанию), а код из 9.6 используется как настроение: много света и воздуха, ничего кричащего, натуральные тёплые полутона. Если Алёна позже назовёт свои цвета — этот файл обновить.

## Цвета

- Фон страницы: `#FBF7F5` (тёплый пудрово-белый)
- Текст: `#332A2E` (тёмный тёпло-графитовый с розовым подтоном)
- Второстепенный текст: `#5C4F54`, `#7A6C71`, `#9B8D92`
- Акцент (пыльная роза): `#9C5F6A` — курсивные выделения в заголовках, нумерация, точки списков, бейджи, рамки результата
- Серые блоки (highlight): `#F4ECEA` — квадратные углы, без цветных линий слева
- Карточки: `#F7F1EF`, рамка `#E8DCD8`
- Советы внутри карточек: `#EFE4E1`
- Линии-разделители: `#ECE1DE`, тонкие линии навбара `#F1E8E5`
- Тёмный фон (титульные слайды, футеры при необходимости): `#332A2E`; на нём акцент — `#E3C2C9` (светлая пудровая роза). Акцент `#9C5F6A` на тёмном фоне НЕ использовать.

CSS-переменные (вставлять в каждый файл):
```css
:root {
  --bg: #FBF7F5; --text: #332A2E; --muted: #5C4F54; --muted-2: #7A6C71; --muted-3: #9B8D92;
  --accent: #9C5F6A; --accent-dark: #E3C2C9;
  --block: #F4ECEA; --card: #F7F1EF; --card-border: #E8DCD8; --tip: #EFE4E1; --line: #ECE1DE; --nav-line: #F1E8E5;
}
```

- Ник в навбаре: DM Sans, italic, `#9B8D92`

## Логотип и навбар

- Графического логотипа пока нет — слева в навбаре текстовая монограмма: `<span class="nav__mono">Ц</span>` (Libre Baskerville, italic, 22px, цвет акцента `#9C5F6A`) — «Ц» от «Царевна». Допустимый вариант — «А», но по умолчанию «Ц».
- Справа — ник курсивом: `the.tsarevna` (DM Sans, italic, `#9B8D92`).
- Когда появится логотип — положить в `~/.claude/brand/logo-alena.png` и заменить монограмму на `<img>` высотой 30px.

## Правила

- Квадратные углы везде (никаких border-radius, кроме круглых точек списков и точек шагов)
- Серые блоки без цветных полос слева
- На тёмном фоне акцент только `#E3C2C9`
- Слова «Claude» и «reels» — только латиницей
- Тексты для аудитории — на «ты», в женском роде
- Настроение вёрстки — из её эстетики (9.6 распаковки): воздух, свет, минимум декора; уместные эмодзи-коды бренда: 👑🐸 (использовать точечно, как у неё в канале, а не как орнамент)
